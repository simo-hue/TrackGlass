# Trackglass for Mac 1.0.0

DRAFT — edit before running `Scripts/release-mac.sh 1.0.0` (the file is attached to the GitHub release verbatim and shown in the in-app update dialog).

The first stable release of the Mac companion for the Trackglass iPhone/iPad app.

- Pointer, clicks, drags and drag lock, two-finger scrolling with momentum, pinch, rotate and smart zoom, following your Mac's own Trackpad settings (tracking speed, tap to click, secondary click, natural scrolling and the gesture switches).
- Three-, four- and five-finger gestures: Spaces, Mission Control, App Exposé, Launchpad / Apps and Show Desktop, following your fingers live on macOS 14–26. On macOS 27 they use keyboard shortcuts and switch when you lift; Launchpad / Apps is not available there.
- Notification Center from the right edge; force click opens Look Up.
- Pairing by QR code or six-digit code, confirmed with an Allow click on the Mac. The long-term key is agreed with a fresh key exchange and never sent over the network. Every connection is encrypted and stays on your local network, so the iPhone or iPad must be on the same Wi‑Fi network as the Mac.
- The "Reduced gesture mode" list (menu bar menu and Settings → Advanced) shows which gestures use a fallback on this Mac.

Requires macOS 14 or later and the Accessibility permission (the Welcome window walks you through it). On macOS 15 or later, also allow Local Network access when macOS asks.

Install: open the DMG and drag Trackglass for Mac to Applications; its icon is in the menu bar. Updates are delivered in-app (a daily check of this project's GitHub repository).
