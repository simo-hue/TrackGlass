# Trackglass for Mac 1.0.0

DRAFT — edit before running `Scripts/release-mac.sh 1.0.0` (the file is attached to the GitHub release verbatim and shown in the in-app update dialog).

The first stable release of the Mac companion for the Trackglass iPhone/iPad app.

- Pointer, clicks, drags and drag lock, two-finger scrolling with momentum, pinch, rotate and smart zoom, following your Mac's own Trackpad settings (tracking speed, tap to click, secondary click, natural scrolling and the gesture switches).
- Three-, four- and five-finger gestures: Spaces, Mission Control, App Exposé, Launchpad / Apps and Show Desktop; Notification Center from the right edge; force click.
- Pairing by QR code or six-digit code, confirmed with an Allow click on the Mac. The long-term key is agreed with a fresh key exchange and never sent over the network; every connection is encrypted and stays on your local network.
- Settings → Advanced shows "Reduced gesture mode" when a macOS update limits a system gesture, and which fallback is in use.

Requires macOS 14 or later and the Accessibility permission (the Welcome window walks you through it).

Install: open the DMG and drag Trackglass for Mac to Applications. Updates are delivered in-app.
